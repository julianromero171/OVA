## 2. Objetivos

**General.** Diseñar e implementar un Objeto Virtual de Aprendizaje (OVA) funcional, accesible y didáctico que permita comprender y enseñar la teoría de la autopoiesis y los sistemas vivos de Maturana y Varela como tema específico de la Teoría General de Sistemas.

**Específicos.**

1. Investigar y sintetizar el marco conceptual (autopoiesis, organización y estructura, clausura operacional, acoplamiento estructural, determinismo estructural, autopoiesis frente a alopoiesis) a partir de fuentes académicas confiables, citadas en APA 7.
2. Aplicar principios de diseño instruccional y de experiencia de usuario: secuencia por módulos, identidad visual propia, navegación clara y diseño adaptable a móviles.
3. Desarrollar contenidos interactivos que fomenten el aprendizaje activo: ejercicios con retroalimentación, cinco juegos y un quiz con puntaje automático.
4. Publicar y socializar el OVA en GitHub Pages y compartir el enlace con el estudiante integrador del tema 24.
5. Sustentar oralmente el proyecto, demostrando dominio del tema y del código desarrollado.

## 4. Herramientas usadas

- **Desarrollo web:** HTML5, CSS3 y JavaScript ES6 sin *frameworks*; Canvas 2D API (simulador), Web Audio API (sonidos), Web Speech API (lectura en voz alta).
- **Diseño visual:** Canva (guía de estilo del autor); Google Fonts: Montserrat y Outfit; formas SVG/CSS propias.
- **Juegos y multimedia:** juegos propios en JavaScript (3), Wordwall y Educaplay (actividades externas), YouTube (videos curados).
- **Publicación:** Git, GitHub y GitHub Pages.
- **Citación:** normas APA 7 y recomendaciones de Varón Castañeda (2017) sobre gestores bibliográficos (Zotero, Mendeley).
- **Inteligencia artificial:** Google Antigravity (Google, 2026), como asistente.

## 5. Metodología

1. **Análisis:** lectura de las orientaciones del proyecto y revisión de fuentes primarias y secundarias; organización de las referencias en APA 7.
2. **Diseño instruccional:** secuencia contexto → teoría → comparación → casos → práctica → evaluación, con retroalimentación inmediata.
3. **Diseño visual:** guía de estilo creada por el autor en Canva y trasladada a CSS propio.
4. **Desarrollo:** código modular (navegación, juegos, quiz, actividades externas) y pruebas en escritorio y móvil.
5. **Publicación y evaluación:** despliegue en GitHub Pages, socialización con el integrador y sustentación oral.
